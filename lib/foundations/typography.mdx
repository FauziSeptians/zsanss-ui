# Typography

Satu font untuk seluruh library: **Inter (variable)** — dipilih karena rapat, terbaca di ukuran
kecil, dan punya angka tabular, cocok untuk antarmuka data-padat seperti ERP.
Kode dan nilai teknis memakai **JetBrains Mono**.

```css
@import "zsanss-ui/fonts.css";   /* Inter + JetBrains Mono, self-hosted via Fontsource */
```

Tidak mau memakai font ini? Cukup override token di project kamu:
`@theme { --font-sans: "Nama Font", ui-sans-serif, system-ui, sans-serif; }`

## Panduan singkat

- Teks tabel & form: `text-sm`. Judul halaman: `text-2xl font-semibold`.
- Selalu pakai warna teks semantik (`text-foreground`, `text-foreground-muted`), bukan `text-gray-*`.
- Jangan set `font-family` manual di komponen; font diwarisi dari `--font-sans`.
